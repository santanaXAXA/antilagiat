Публичный API

Отправьте POST-запрос с текстом — получите JSON с результатами анализа.

Endpoint
POST https://web-production-ea6bac.up.railway.app/api/check
Запрос (JSON)
{ "text": "Ваш текст для проверки..." }
Ответ (JSON)
{
  "ok": true,
  "originality": 72,
  "borrowing": 8,
  "citation": 5,
  "ai": 15,
  "stats": {
    "chars": 1240,
    "words": 198,
    "sentences": 12,
    "unique_words": 143,
    "avg_sent_len": 16.5
  }
}
Пример на Python
import requests

r = requests.post(
    "https://web-production-ea6bac.up.railway.app/api/check",
    json={"text": "Ваш текст здесь..."}
)
print(r.json())
Пример на JavaScript
const res = await fetch(
  "https://web-production-ea6bac.up.railway.app/api/check",
  {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({ text: "Ваш текст здесь..." })
  }
);
const data = await res.json();
console.log(data);
