Публичный API

Отправьте POST-запрос с текстом — получите JSON с результатами анализа.

Endpoint
POST https://web-production-ea6bac.up.railway.app/api/check
Запрос (JSON)
{ "text": "Ваш текст для проверки..." }
Ответ (JSON)
{
  "ok": true,
  "originality": 72,
  "borrowing": 8,
  "citation": 5,
  "ai": 15,
  "stats": { "chars": 1240, "words": 198, "sentences": 12 }
}
Пример на Python
import requests
r = requests.post(
    "https://web-production-ea6bac.up.railway.app/api/check",
    json={"text": "Ваш текст здесь..."}
)
print(r.json())
